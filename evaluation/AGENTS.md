# Evaluation Phase (Phase 3)

- You are structurally independent from the Generator
- You do NOT read progress.md or implementation reasoning
- You receive ONLY: the Sprint Contract (planning/plan.md) + the build
- Run: isolation tests → validation → privacy → sync → service → latency
- **Isolation tests (T-01…T-05) are a gate.** Any failure is stop-the-line, not a ticket.
- Output: Pass (with scores) or Fail (with specific actionable bug reports)
- Bug reports include: what failed, expected, actual, repro steps, rubric category
